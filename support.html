Common questions

Câu hỏi thường gặp

The first scan takes a long time. The first ID scan reads every Photoshop file and exported image in your scan folders, so it can take several minutes, longer with many images. Later scans read only new or changed files and usually finish in seconds.

How do I make a new version? Use File → Save As with a new name. The new file appears right above the file it came from.

I renamed or moved a file. Is it lost? No. FindID writes a small ID into the file, so it still knows the file after a rename, move or copy. If you moved it outside your scan folders, add the new folder in Settings → Folders to scan.

FindID can't find the PSD of an exported image. Save As, Save a Copy and Save for Web keep the ID in the image. Export As and Quick Export do not, so FindID compares the picture itself instead. That works for the whole image or a slightly cropped one; a heavily cropped image (about 70 % of the picture or less) usually gives no result.

Does FindID upload my files? No. It runs only on your computer and sends nothing over the internet.

Can I use it on more than one computer? Yes, on any number of computers you use yourself. A team needs one licence per person.

I lost my download link. Bought on findid.app: open the receipt email from Creem, which has the download link, or write to support@findid.app from the email you bought with. Bought on Adobe Creative Cloud Marketplace: Creative Cloud installs it again for you. You never pay twice.

Lần quét đầu lâu quá. Lần quét ID đầu tiên đọc mọi file Photoshop và ảnh đã xuất trong các thư mục quét, nên có thể mất vài phút, nhiều ảnh thì lâu hơn. Những lần sau chỉ đọc file mới hoặc đã đổi, thường xong trong vài giây.

Tạo version mới thế nào? Dùng File → Save As với tên mới. File mới hiện ngay trên file gốc của nó.

Đổi tên hay chuyển file đi chỗ khác thì có mất không? Không. FindID ghi một ID nhỏ vào file, nên vẫn nhận ra file sau khi đổi tên, chuyển chỗ hay sao chép. Nếu chuyển ra ngoài các thư mục quét, thêm thư mục mới ở Cài đặt → Thư mục quét.

FindID không tìm ra PSD của một ảnh đã xuất. Save As, Save a Copy và Save for Web giữ ID trong ảnh. Export As và Quick Export thì không, nên FindID so chính hình ảnh. Cách này tìm được với ảnh nguyên hoặc cắt ít; ảnh cắt nhiều (còn khoảng 70 % hình hoặc ít hơn) thường không ra kết quả.

FindID có tải file của tôi lên mạng không? Không. FindID chỉ chạy trên máy bạn và không gửi gì lên mạng.

Dùng trên nhiều máy được không? Được, trên bao nhiêu máy cũng được nếu là máy của chính bạn. Nhóm nhiều người thì mỗi người một bản quyền.

Mất link tải. Mua trên findid.app: mở email hoá đơn của Creem, trong đó có link tải, hoặc gửi mail tới support@findid.app bằng email đã dùng để mua. Mua trên Adobe Creative Cloud Marketplace: Creative Cloud tự cài lại cho bạn. Không bao giờ phải mua lại.
